# 杭州链家租房数据爬虫

> 基于 Playwright + GeeTest v4 自动验证码破解的链家租房数据全量采集系统

## 项目简介

针对链家网杭州站（hz.lianjia.com）的租房数据进行全量采集，覆盖杭州市 10 个行政区的整租/合租房源。通过三维交叉筛选策略突破链家 100 页分页限制，结合云码平台实现 GeeTest v4 点击式验证码的自动破解，最终采集 48,308 条原始数据。

## 采集规模

| 指标 | 数值 |
|------|------|
| 覆盖行政区 | 上城、拱墅、西湖、滨江、余杭、萧山、临平、钱塘、富阳、临安 |
| 租赁方式 | 整租、合租 |
| 价格区间 | 8 段（1000 以下 ~ 10000 以上） |
| 数据组合 | 160 个（10 × 2 × 8） |
| 采集总量 | 48,308 条 |
| 涉及小区 | 5,802 个 |

## 技术方案

### 突破分页限制

链家单个搜索最多返回 100 页（2,000 条）。采用三维交叉筛选：

```
行政区（10个）× 租赁方式（2种）× 价格区间（8段）= 160 个子搜索
```

每个子搜索的房源量控制在 2,000 条以内，确保数据完整性。

### 浏览器自动化

- Playwright 通过 CDP 连接用户已登录的 Edge 浏览器
- 复用浏览器登录态 Cookie，无需处理登录流程
- 启动方式：`start msedge --remote-debugging-port=9222`

### GeeTest v4 验证码破解

链家使用 GeeTest v4 点击式验证码，要求按语义顺序点击 3 个字符/图标。破解流程：

1. 截取验证码弹窗区域
2. Base64 编码发送至云码平台 API（type=88888）
3. 返回点击坐标，模拟鼠标完成验证
4. 失败自动重试

### 反爬策略

- 每页随机延迟 8-15 秒
- 每批次（100 条）间隔 60 秒
- 支持断点续爬（进度持久化至 `crawl_progress.json`）
- 遇到登录过期或余额不足自动安全停止

## 快速开始

### 环境要求

- Python 3.9+
- Microsoft Edge 浏览器
- 云码平台账号（[注册](https://www.jfbym.com)）

### 安装

```bash
pip install -r requirements.txt
playwright install chromium
```

### 配置

复制 `.env.example` 为 `.env`，填入云码平台 Token：

```env
YUNMA_TOKEN=your_yunma_token_here
AMAP_API_KEY=your_amap_api_key_here
```

### 运行

```bash
# 1. 启动 Edge 调试模式
start msedge --remote-debugging-port=9222

# 2. 在 Edge 中登录链家网

# 3. 运行爬虫
python src/01_rent_crawler.py
```

## 注意事项

1. 爬虫依赖 Edge 浏览器登录态，Cookie 过期需重新登录
2. 云码平台按次计费，全量爬取约需 200-500 次识别
3. 链家有反爬机制，被拦截后需更换 IP 或账号
4. 数据为采集时点快照，房源更新较快
