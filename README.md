# 基于 GIS 的杭州城市租房价格空间监测与通勤因果分析系统

> 杭州市链家租房数据全量采集、清洗、地理编码与空间分析系统

## 项目简介

本系统面向城市租房价格空间分布研究，以链家网（hz.lianjia.com）为数据源，对杭州市 10 个主城区的租房信息进行全量采集。通过 Playwright 浏览器自动化 + GeeTest v4 验证码自动破解实现大规模数据采集，结合高德地图地理编码将房源定位到经纬度坐标，最终输出可供 GIS 空间分析使用的结构化数据集。

**核心亮点：**

- 10 个行政区 × 2 种租赁方式 × 8 个价格段 = **160 个数据组合**全覆盖
- GeeTest v4 点击式验证码**自动识别破解**
- 46,350 条清洗后数据，**99.1% 带精确坐标**
- 三阶段处理流水线：采集 → 清洗 → 地理编码

## 技术方案

### 1. 数据采集

**目标网站**：链家网杭州站（hz.lianjia.com/zufang/）

**采集策略**：链家单个搜索条件最多返回 100 页结果（每页 20 条，上限 2,000 条）。为突破此限制，采用三维交叉筛选：

- **维度一**：10 个行政区（上城、拱墅、西湖、滨江、余杭、萧山、临平、钱塘、富阳、临安）
- **维度二**：2 种租赁方式（整租、合租）
- **维度三**：8 个价格区间（1000 以下 ~ 10000 以上）

组合后共 160 个子搜索，每个子搜索的房源量控制在 2,000 条以内，确保数据完整性。

**浏览器自动化**：使用 Playwright 通过 CDP（Chrome DevTools Protocol）连接用户已登录的 Edge 浏览器，复用登录态 Cookie，避免处理复杂的登录流程。

**验证码破解**：链家使用 GeeTest v4 点击式验证码，要求按语义顺序点击 3 个字符/图标。通过云码平台 API（type=88888）实现自动识别：

1. 截取验证码弹窗区域
2. Base64 编码后发送至云码 API
3. 获取点击坐标，模拟鼠标点击
4. 验证失败自动重试

**反爬措施**：

- 每页随机延迟 8-15 秒
- 每批次（100 条）间隔 60 秒
- 模拟真实用户浏览行为
- 支持断点续爬（进度持久化至 `crawl_progress.json`）

### 2. 数据清洗

| 处理步骤 | 说明 |
|---------|------|
| 去重 | 基于标题+小区+户型+面积去重 |
| 租金过滤 | 移除 < 100 元/月或 > 100,000 元/月的异常值 |
| 面积过滤 | 移除 < 5 m² 或 > 1,000 m² 的异常值 |
| 区域标准化 | 统一行政区名称格式 |
| 单价计算 | 新增"单价"字段 = 租金 ÷ 建筑面积（元/m²/月） |

### 3. 地理编码

**API**：高德地图 Web 服务地理编码 API

**编码策略**：多级地址匹配，逐步降级以提高成功率：

1. `杭州市 + 行政区 + 小区名称`（精确匹配）
2. `杭州市 + 小区名称`（去掉区域约束）
3. 仅 `小区名称`（最宽松匹配）

**缓存机制**：已编码的小区坐标写入 `geocode_cache.json`，避免重复调用 API。5,802 个小区中仅 48 个编码失败，整体覆盖率 99.1%。

**坐标系**：高德 GCJ-02 坐标系，可直接用于高德/腾讯地图前端渲染。

## 快速开始

### 环境要求

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | 3.9+ | 运行环境 |
| Microsoft Edge | 最新版 | 浏览器自动化 |
| 云码平台账号 | — | GeeTest 验证码识别（[注册地址](https://www.jfbym.com)） |
| 高德地图 API Key | — | 地理编码服务（[申请地址](https://console.amap.com/dev/key/app)） |

### 安装依赖

```bash
pip install -r requirements.txt
playwright install chromium
```

### 配置环境变量

复制 `.env.example` 为 `.env`，填入你的密钥：

```env
# 云码平台 Token
YUNMA_TOKEN=your_yunma_token_here

# 高德地图 API Key
AMAP_API_KEY=your_amap_api_key_here
```

### 运行

**一键执行全流程：**

```bash
python src/main.py
```

**分步执行：**

```bash
# 1. 启动 Edge 调试模式
start msedge --remote-debugging-port=9222

# 2. 在 Edge 中登录链家网，然后运行爬虫
python src/01_rent_crawler.py

# 3. 数据清洗
python src/02_data_cleaning.py

# 4. 地理编码
python src/03_geocoding.py
```

## 注意事项

1. **登录态依赖**：爬虫通过 CDP 连接已登录的 Edge 浏览器，Cookie 过期需重新登录
2. **验证码费用**：云码平台按次计费，全量爬取约需 200-500 次识别
3. **API 配额**：高德地图地理编码每日免费额度 5,000 次，5,802 个小区需要分两天完成
4. **IP 限制**：链家有反爬机制，建议配合代理 IP 使用；被拦截后需更换 IP
5. **数据时效**：数据为 2026 年 5 月采集时点的快照，链家房源更新较快
6. **坐标系**：使用高德 GCJ-02 坐标系，如需 WGS-84 需做坐标转换
